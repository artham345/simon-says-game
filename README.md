# 🎮 Simon Says Game

A classic **Simon Says memory game** built using **HTML, CSS, and JavaScript**.  
Test your memory skills by repeating an ever-growing sequence of colors. Each correct round increases the difficulty!

---

## 🧠 How the Game Works
- The game flashes a sequence of colors.
- The player must repeat the sequence in the correct order.
- Each successful round adds a new color to the sequence.
- The game ends when the player clicks the wrong color.

---

## 🚀 Features
- Interactive and responsive UI
- Random color sequence generation
- Increasing difficulty with each level
- Real-time user input validation
- Game over and restart functionality

---

## 🛠️ Technologies Used
- **HTML** – Structure of the game
- **CSS** – Styling and animations
- **JavaScript** – Game logic and interactivity

---

## ▶️ How to Play
1. Open the game in your browser
2. Press any key to start the game
3. Watch the color sequence carefully
4. Click the colors in the same order
5. Try to reach the highest level possible!
